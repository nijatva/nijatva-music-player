What it does

Songs, albums, artistsFolders and genres too, all built from what is actually on the device.
A live queueShuffle, repeat one, repeat the queue, and a sleep timer that stops when you do.
Four themes, three accentsSystem, Dark, Light and Black, with Green, Saffron or Indigo.
A real equaliserFlat, Bass, Vocal, Treble and Warm, from five filters across the band.
Tags read locallyID3 titles, artists, albums and cover art, parsed on the device and never uploaded.
Lock screen controlsMedia Session in the browser, a media notification on Android.

Install on Android

  1. Download the APKFrom the latest release. It is nijatva-music-1.1.2-debug.apk.
  2. Allow the installAndroid asks once whether this browser may install apps. Say yes, then open the file.
  3. Grant audio accessThe player reads your media library; without that permission the list stays empty.
This build is debug-signed. It is not on Google Play and not signed for release, so Android will warn you about an unknown source. That is expected for a sideloaded build from CI.

Build it yourself

./gradlew :composeApp:assembleDebug   # Android APK
./gradlew :composeApp:run             # desktop app

# the web player has no build step at all:
open web/index.html
Desktop playback needs VLC installed. The web player is web/index.html — any browser opens it, and the published copy lives in docs/player/.
