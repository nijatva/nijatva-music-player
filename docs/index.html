Music
a Nijatva app

Your music, played offline.

A small audio player for the files already on your device. One Compose Multiplatform codebase for Android and desktop, plus a web player that runs in the browser tab with no install at all. No accounts, no ads, no analytics, no Google Play Services.

Open the web player Install it on your phone Source on GitHub Builds

Platforms

AndroidMedia3 (ExoPlayer) + MediaStore library · package com.nijatva.music.player
Windows · macOS · LinuxlibVLC via vlcj, reading ~/Music and ~/Downloads
WebHTML5 audio, tags read in the tab, Web Audio equalizer — no build step
Web appInstallable: add it to your home screen and it opens offline as a standalone app

What it does

  • Songs, albums, artists, folders, genres and a live queue, built from what is on the device.
  • Shuffle, repeat one or repeat queue, a sleep timer and a favourite list.
  • Four themes (System, Dark, Light, Black) and three accents (Green, Saffron, Indigo).
  • ID3 titles, artists, albums and cover art read locally — never uploaded.
  • Equalizer presets: Flat, Bass, Vocal, Treble, Warm.

Build

./gradlew :composeApp:assembleDebug   # Android APK
./gradlew :composeApp:run             # desktop app

Desktop playback needs VLC installed. The web player is web/index.html — open it in any browser.
